# Doviz_Ofisi

# 💰 Döviz Ofisi Uygulaması 🌍

Bu proje, döviz alım-satım işlemleri için geliştirilen basit bir Windows Forms uygulamasıdır. Uygulama, TCMB (Türkiye Cumhuriyet Merkez Bankası) sitesinden güncel döviz kuru bilgilerini alarak kullanıcıların döviz alış ve satış işlemlerini hesaplamalarına olanak sağlar. 📉💵

## 🛠️ Kullanılan Teknolojiler

- C# (.NET Framework)
- Windows Forms
- Visual Studio
- XML Veri İşleme (TCMB API)

## 🎯 Uygulama Özellikleri

- ✅ TCMB'den güncel döviz kuru verisini çekme (USD ve EUR)
- ✅ Döviz alış ve satış fiyatlarını gösterme
- ✅ Kullanıcıya döviz alım veya satım işlemi gerçekleştirme imkanı
- ✅ Döviz tutarlarını hesaplama
- ✅ Kullanıcı dostu arayüz

## 💵 Döviz Kurları

- USD Alış: TCMB'den alınan güncel USD alış kuru
- USD Satış: TCMB'den alınan güncel USD satış kuru
- EUR Alış: TCMB'den alınan güncel EUR alış kuru
- EUR Satış: TCMB'den alınan güncel EUR satış kuru

## 🚀 Başlatmak İçin

Projeyi Visual Studio’da açarak çalıştırabilirsiniz. Uygulama, açıldığında TCMB'den en güncel döviz kurlarını otomatik olarak çeker. Döviz alım/satım işlemleri için ilgili butonlara tıklayarak işlem yapabilirsiniz.
